Privacy Policy

Last updated: October 28, 2026

This policy covers the AI Anvil website at aianvil.app and BigBrain, a private, self-hosted household assistant operated for a single household. It explains what data is collected, how it is used, and the choices available to you.

Who operates this

AI Anvil and BigBrain are operated privately for a single household. They are not a company, a public service, or a commercial product. There is no public contact address; household members can reach the operator through the private channel they already use.

This website

The AI Anvil website is a static site hosted on GitHub Pages and served through Cloudflare's DNS. It does not set cookies, run analytics, use advertising pixels, or include third-party tracking scripts. GitHub and Cloudflare may process standard technical information (such as IP address and request metadata) to deliver the site and protect it from abuse, under their own privacy policies.

Google user data

BigBrain requests access to Google Calendar only when a household member chooses to connect it. The specific scope requested is:

  • https://www.googleapis.com/auth/calendar.events

This scope allows BigBrain to read, create, update, and delete events on the Google Calendar that the member connects. BigBrain does not request access to Gmail, Google Drive, Google Contacts, or any other Google service.

How Google data is used

Calendar event details — including title, description, location, start time, and end time — are used to:

  • display the household calendar inside BigBrain;
  • keep events in sync between BigBrain and Google Calendar, including changes made in either place;
  • answer a member's own requests in chat, such as asking what is on the calendar for a given day.

Storage

Calendar data is stored in a self-hosted PostgreSQL database on infrastructure controlled by the operator. Google OAuth refresh tokens are encrypted at rest. Encrypted backups may be stored with a cloud storage provider.

Sharing

We do not sell Google user data, use it for advertising, or share it with third parties except as needed to run the service:

  • AI model providers. The operator configures which AI model BigBrain uses (for example, DeepSeek or OpenRouter). Chat context, which may include calendar event details, is sent to that provider to generate a response.
  • Infrastructure providers. Cloudflare provides access control and may provide encrypted backup storage; GitHub Pages hosts this website. These providers process data on the operator's behalf.
  • Legal requirements. Data may be disclosed where required by law.

Retention and deletion

Calendar data remains until it is deleted or the Google Calendar connection is removed. Disconnecting removes the stored refresh token; events already synced to the local database remain until they are deleted. To request deletion of your data, contact the operator through the private household channel you already use.

Revoking access

You can revoke BigBrain's access to your Google Account at any time from Google Account permissions. You can also disconnect Google Calendar from BigBrain's settings.

Google API Services User Data Policy

BigBrain's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Security

Access to BigBrain is limited to invited household members through Cloudflare Access and application credentials. Data in transit is protected with HTTPS. No system is perfectly secure, but access is kept deliberately narrow.

Children

BigBrain is a household tool, not a service directed at the general public. It is not offered to strangers and has no public registration.

Changes to this policy

This policy may be updated as the household's tools change. The date at the top of this page reflects the latest revision. Material changes affecting Google user data will be reflected here.

Contact

This is a private, invitation-only application. If you are a household member, contact the operator through the private channel you already use. There is no public contact address.
